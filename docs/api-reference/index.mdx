# API reference

The SDK exports `LiquidiumClient`, error types, constants, module request types, response types, and wallet action types from `@liquidium/client`.

## Client modules

The client provides the following modules:

| Module | Purpose |
| --- | --- |
| `client.accounts` | Profile lifecycle, account lookup, and linked wallets |
| `client.activities` | Activity lists and receipt-oriented status |
| `client.history` | User history and confirmed protocol-wide activity through the Liquidium SDK API |
| `client.simpleLoans` | Accountless Simple Loans with generated deposit and repayment targets |
| `client.lending` | Supply, borrow, withdraw, and inflow reporting |
| `client.liquidations` | Candidate scanning, slippage-protected liquidation execution, and status lookup |
| `client.market` | Pools, prices, and pool rate lookups |
| `client.positions` | Per-pool positions, health, and aggregate stats |
| `client.quote` | Pure quote helpers from market inputs |

## Shared status types

Use [`LiquidiumStatus`](./generated/interfaces/LiquidiumStatus.md) for flow state across Simple Loans, activities, lending responses, and history entries.

The following types define shared status data:

| Type | Purpose |
| --- | --- |
| [`LiquidiumStatus`](./generated/interfaces/LiquidiumStatus.md) | Operation, state, and optional confirmation progress |
| [`LiquidiumOperation`](./generated/type-aliases/LiquidiumOperation.md) | `deposit`, `borrow`, `repayment`, `withdrawal`, or `liquidation` |
| [`LiquidiumState`](./generated/type-aliases/LiquidiumState.md) | `action_required`, `confirming`, `processing`, `active`, `completed`, `failed`, or `expired` |
| [`Activity`](./generated/type-aliases/Activity.md) | Inflow or outflow activity returned by activity APIs |
| [`GetActivityStatusResponse`](./generated/type-aliases/GetActivityStatusResponse.md) | Found or missing result from `client.activities.getStatus(...)` |

For UI guidance, see the [status system](../concepts/status-system.mdx).

For APR and estimated APY semantics, see [market data](../concepts/market-data.mdx).

## Error behavior

Public SDK methods can reject with
[`LiquidiumError`](./generated/classes/LiquidiumError.md). Branch on its stable
[`LiquidiumErrorCode`](./generated/variables/LiquidiumErrorCode.md) value
instead of parsing `message`.

`client.simpleLoans.create(...)` can also reject with
[`SimpleLoanCreatedError`](./generated/classes/SimpleLoanCreatedError.md) after
the remote loan is created but before the SDK loads its hydrated state. Recover
the loan with the error's `loanId` or `ref`. Do not call `create(...)` again.

For retry decisions and recovery code, see [Handle errors](../guides/error-handling.mdx).

## Liquidations

Use `client.liquidations.scan(request)` for cursor-based candidate discovery, `client.liquidations.liquidate(request)` for slippage-protected execution, and `client.liquidations.getLiquidation(liquidationId)` for status lookup. The SDK exports these public types:

| Type | Purpose |
| --- | --- |
| `ScanLiquidationsRequest` | Optional cursor, accounts to scan, and maximum candidates to return |
| `LiquidationScanResult` | Candidates, scanned account count, and next cursor |
| `LiquidationCandidate` | Liquidatable borrower, health factor, total debt, and pool positions |
| `LiquidationCandidatePosition` | Pool, asset, debt, collateral, threshold, bonus, and protocol fee |
| `LiquidationCandidateAsset` | Supported asset symbol or legacy SOL candidate symbol |
| `ExecuteLiquidationRequest` | Borrower, pools, debt amount, receiver, required minimum collateral, and optional bad-debt choice |
| `LiquidationResult` | Liquidation id, timestamp, amounts, assets, lifecycle state, and transfer states |
| `LiquidationAmounts` | Debt repaid and net collateral received in base units |
| `LiquidationAsset` | Chain-key ledger principal or unknown asset type |
| `CkLiquidationAsset` | Chain-key ledger route with its required ledger canister principal |
| `UnknownLiquidationAsset` | Asset route the lending canister cannot identify |
| `LiquidationStatus` | Progress, success, or failed lifecycle status |
| `LiquidationProgressStatus` | Pending or processing lifecycle state without an error |
| `LiquidationSuccessStatus` | Successful lifecycle state without an error |
| `LiquidationFailedStatus` | Failed lifecycle state with its required protocol error |
| `LiquidationTransfer` | Pending, successful, or failed collateral or change transfer |
| `LiquidationPendingTransfer` | Pending transfer without an error |
| `LiquidationSuccessTransfer` | Successful transfer without an error |
| `LiquidationFailedTransfer` | Failed transfer with its required error |

See [Liquidations](../guides/liquidations.mdx) for allowance, slippage, receiver, and refund requirements.

## History

Use `client.history.getUserTransactionHistory(profileId, filters?)` for paginated profile transaction history. It accepts `cursor`, `limit`, `market`, `poolId`, `operations`, `states`, `from`, and `to`.

Use `client.history.getLiquidationHistory(profileId, filters?)` for paginated liquidation history. It accepts `cursor`, `limit`, `market`, `poolId`, `from`, and `to`.

Continue pagination with the opaque `nextCursor` value.

Use `client.history.getProtocolActivity(filters?)` for recent confirmed activity across the protocol. It calls `GET /v2/history/activities`, accepts `poolId`, `operations`, and `limit`, and returns an unpaginated array with each pool's `asset`, `decimals`, and base-unit `amount`. History and protocol activity entries expose `txids?: string[]`.

## Asset identifiers

`AssetIdentifier` is a union of named types for each supported asset and
transfer-chain pair.

| Type | Asset | Chain |
| --- | --- | --- |
| `BtcOnBtcAssetIdentifier` | `BTC` | `BTC` |
| `EthOnEthAssetIdentifier` | `ETH` | `ETH` |
| `UsdcOnEthAssetIdentifier` | `USDC` | `ETH` |
| `UsdtOnEthAssetIdentifier` | `USDT` | `ETH` |
| `BtcOnIcpAssetIdentifier` | `BTC` | `ICP` |
| `EthOnIcpAssetIdentifier` | `ETH` | `ICP` |
| `IcpOnIcpAssetIdentifier` | `ICP` | `ICP` |
| `UsdcOnIcpAssetIdentifier` | `USDC` | `ICP` |
| `UsdtOnIcpAssetIdentifier` | `USDT` | `ICP` |
