# Install the SDK

Install the client package in your app:

```bash
npm install @liquidium/client
```

## Package runtime support

The published package provides ECMAScript module (ESM) and CommonJS entry
points. Your runtime must provide global `fetch` and `BigInt` support. The
package does not declare a Node.js engine range.

## Build the repository

To build and test a local checkout, follow these steps:

1. Clone the repository and enter its directory:

   ```bash
   git clone https://github.com/Liquidium-Inc/liquidium-sdk.git
   cd liquidium-sdk
   ```

2. Install the [Vite+ CLI](https://viteplus.dev/guide/), then install the workspace dependencies with Bun:

   ```bash
    bun install
   ```

3. Build, type-check, and test the workspace:

   ```bash
    bun run build
    bun run lint
    bun run typecheck
    bun run test
   ```

The repository development tools have the following requirements:

| Requirement | Notes |
| --- | --- |
| Node.js | 22.22.3 or later in the 22.x line, 24.x, or 26 or later |
| Bun | 1.4.4 or later for local development |
| Vite+ | 1.5.0, pinned in the workspace catalog |

`bun run lint` runs formatting, type-aware lint, and TypeScript checks through
Vite+. All generic anti-slop rules run at error severity. The formatter keeps
the repository's 80-column, double-quote, semicolon, and ES5 trailing-comma style.
Generated files and installed agent tools are excluded from these checks.
