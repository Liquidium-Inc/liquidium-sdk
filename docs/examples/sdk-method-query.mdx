# Run the SDK method query example

Use `examples/sdk-method-query` to call SDK methods from a Vite React app that loads Dynamic.

:::warning Mainnet operations

This example uses bundled mainnet canister and production service defaults.
SOL uses the bundled production pool. No API URL or SOL pool override is needed.
It exposes state-changing SDK methods that can create protocol state or submit
wallet transactions. Review the selected method and all arguments before you
select **Run method**.

:::

The method query screen provides the following capabilities:

| Capability | Use |
| --- | --- |
| Method dropdown | Pick an SDK method |
| JSON editor | Edit method arguments |
| Method argument type | Inspect request types and their declaration comments, including string-union aliases |
| Wallet defaults | Apply connected-wallet values where relevant |
| Raw result view | Inspect return payloads |

The execution mode defaults to **Mock wallet**, which does not open wallet
prompts. SDK calls still use production and can change protocol state.
Select **Connected wallet** to sign messages or send transfers with an ETH or
SOL wallet. This mode ignores mock signatures and transaction IDs for wallet
execution. Review the account, destination, and amount before running a method.

## Start the example

Use Node.js 22.22.3 or later in the 22.x line, 24.x, or 26 or later. Use
Bun 1.4.4 or later and the Vite+ CLI.

To start the example, follow these steps:

1. From the SDK root, install the workspace dependencies:

   ```bash
    bun install
   ```

2. Optional: To enable Ethereum reads, copy the environment template:

   ```bash
   cp examples/sdk-method-query/.env.example examples/sdk-method-query/.env
   ```

   Set `VITE_EVM_RPC_URL` to a complete Ethereum mainnet Remote Procedure Call
   (RPC) URL, or set `VITE_INFURA_API_KEY` to an Infura API key. Values with the
   `VITE_` prefix are included in the browser bundle. Use only browser-safe,
   restricted credentials.

3. Start the example:

   ```bash
    bun run --filter @liquidium/example-sdk-method-query dev
   ```

4. Open the local URL that Vite prints.

The page shows **SDK Method Query** when the example starts.

Included method templates cover account, market, position, activity, history, quote, lending, and Simple Loans methods.

The example validates JSON before it calls an SDK method. Use integer strings
for token amounts. Quote pool fields that use `bigint` also accept integer
strings; the example converts them before it calls `quote.getQuote`.
