# Run the contract-interaction example

Use `examples/contract-interaction-flow` to inspect wallet-executed native ETH and ERC-20 supply and repayment flows.

From the SDK root, install dependencies and start the example:

```bash
pnpm install
pnpm --filter @liquidium/example-contract-interaction-flow dev
```

Set `VITE_EVM_RPC_URL` or `VITE_INFURA_API_KEY` to override the example's public mainnet RPC fallback used for USDC and USDT reads. Native ETH contract interaction does not require allowance or token-balance reads.
